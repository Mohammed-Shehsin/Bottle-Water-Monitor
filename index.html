Firmware code

Upload this Arduino IDE sketch to the ESP32

The sketch reads the HC-SR04 and sends one JSON measurement every 500 ms over USB Serial at 115200 baud.

Ready to copy 
// ESP32 + HC-SR04 bottle water-level monitor
// Author: Shehsin Thamarachalil Abdulresak
// Wiring: TRIG -> GPIO 5, ECHO -> voltage divider -> GPIO 27
// Serial output: one JSON object per line at 115200 baud

const int TRIG_PIN = 5;
const int ECHO_PIN = 27;

const float EMPTY_DISTANCE_CM = 30.0;  // sensor-to-bottom distance
const float FULL_DISTANCE_CM  = 6.0;   // sensor-to-water distance at 100%

float readDistanceCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(3);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  unsigned long duration = pulseIn(ECHO_PIN, HIGH, 30000);
  if (duration == 0) return NAN;

  return (duration * 0.0343f) / 2.0f;
}

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  Serial.begin(115200);
}

void loop() {
  float distance = readDistanceCm();

  if (!isnan(distance)) {
    float level = 100.0f *
      (EMPTY_DISTANCE_CM - distance) /
      (EMPTY_DISTANCE_CM - FULL_DISTANCE_CM);

    level = constrain(level, 0.0f, 100.0f);

    Serial.print("{\"distance_cm\":");
    Serial.print(distance, 1);
    Serial.print(",\"level_percent\":");
    Serial.print(level, 1);
    Serial.println("}");
  }

  delay(500);
}
Upload checklist: Select your ESP32 board and COM port in Arduino IDE, upload the sketch, then open this website in desktop Chrome or Edge. Select the same COM port, choose 115200 baud, and click Connect.

Dashboard procedure

Use the live ESP32 page

  1. Build safely: power the HC-SR04 from 5 V and protect ECHO with the resistor divider shown above.
  2. Upload firmware: copy the sketch, upload it to the ESP32, and keep the USB cable connected.
  3. Connect: choose USB Serial / COM, select the authorized port, choose 115200 baud, then press Connect.
  4. Verify: the status changes to live ESP32 data and the bottle, percentage, distance, and history update together.
